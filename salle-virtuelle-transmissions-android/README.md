# Salle Virtuelle Transmissions — Android

Prototype Android du projet « Salle virtuelle – Traditions de l’arme des Transmissions ».

## Ouvrir dans Android Studio
1. Décompresser le ZIP.
2. Ouvrir Android Studio.
3. Choisir **Open**.
4. Sélectionner le dossier **SalleVirtuelleTransmissions**.
5. Laisser Android Studio effectuer la synchronisation Gradle.
6. Pour lancer sur un téléphone : activer le débogage USB et cliquer sur **Run**.
7. Pour créer un APK : **Build > Build App Bundles or APKs > Build APK(s)**.

## Version
- compileSdk: 36
- targetSdk: 36
- minSdk: 26
- Java 17
- Gradle 8.13
- Android Gradle Plugin 8.13.0

## Fonctionnalités de la démo
- Connexion
- Création de compte local
- Navigation fixe en bas
- Accueil
- Histoire
- Patrimoine
- Visite virtuelle (zone prévue)
- Profil / déconnexion
- Contenu hors ligne

> Les comptes de cette version sont stockés localement. Une version institutionnelle devra utiliser une authentification sécurisée et validée.
